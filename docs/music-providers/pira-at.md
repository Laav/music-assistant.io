# PIRA.AT

The PIRA.AT provider adds a curated catalogue of live Dutch pirate radio stations to Music Assistant.

## Features

| | |
|:--|:--:|
| Subscription | Free |
| Login method | None |
| Media types | Radio |
| Browse | All stations and regions |
| Search | Station name, region, source and available now-playing information |

## Configuration

No configuration is required. Add **PIRA.AT** from **Settings** → **Providers** → **Add a new provider**.

## Usage

Open **Browse** and select **PIRA.AT** to see all currently available stations or browse them by region. Select a station to play it immediately, add it to your library or use it in a queue.

The station catalogue changes regularly. A station that is temporarily unavailable may not appear until it is live again.

## Notes

- PIRA.AT provides live radio streams; stream availability and the number of listed stations can change.
- The provider refreshes its catalogue regularly and uses the current stream URL when playback starts.
